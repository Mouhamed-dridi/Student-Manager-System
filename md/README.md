# Planify (RecipeApp)

Planify is a Flutter-based mobile application designed to help users discover delicious recipes and plan their meals seamlessly.

## Features
- **Browse Recipes:** Explore a wide variety of recipes.
- **Meal Planning:** Plan your weekly meals with the Planify feature.
- **Smooth Navigation:** Persistent bottom navigation for easy access to all app features.
- **Responsive UI:** Includes shimmer loading effects for a premium feel.

## Tech Stack
- **Flutter & Dart**
- **GetX** for State Management
- **HTTP** for API communication
- **Persistent Bottom Nav Bar** for main navigation
- **Shimmer** for loading animations

## Getting Started

To run this project locally:

1. Ensure you have [Flutter](https://docs.flutter.dev/get-started/install) installed.
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to start the application on your connected device or emulator.
