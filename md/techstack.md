# Technology Stack

## Frontend Framework
- **Flutter:** The core framework used for building the cross-platform mobile application (Android & iOS).
- **Dart:** The programming language used for Flutter development.

## State Management & Routing
- **GetX (`get`):** Used for high-performance state management, dependency injection, and route management.

## Networking
- **HTTP (`http`):** Used for making API requests to fetch recipes and other data from backend services.

## UI Components & UX
- **Persistent Bottom Nav Bar (`persistent_bottom_nav_bar_v2`):** Used for the main application navigation, ensuring a consistent bottom tab bar across different screens.
- **Shimmer (`shimmer`):** Used to display skeleton loading animations while fetching data, providing a premium user experience.
- **Cupertino Icons:** For iOS-styled icons.
